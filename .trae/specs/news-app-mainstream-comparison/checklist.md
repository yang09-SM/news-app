# Checklist - 新闻APP迭代升级验证清单

## Phase 1: 基础设施加固 验证

- [ ] Redis缓存层集成验证
  - [ ] Redis连接成功（ping返回PONG）
  - [ ] 热门新闻列表接口响应时间 < 50ms（命中缓存时）
  - [ ] 新闻详情页缓存生效（首次请求走DB，后续请求走Redis）
  - [ ] 发布新闻后旧缓存自动失效
  - [ ] 推荐结果按userId隔离存储，不同用户看到不同缓存
  - [ ] 并发请求同一未缓存key时，只有一个请求回源DB（防击穿）
  - [ ] Redis服务不可用时，系统降级为直连DB（不报错）

- [ ] Elasticsearch全文搜索验证
  - [ ] ES集群连接正常（health=green/yellow）
  - [ ] 新闻发布/编辑后ES索引自动同步（延迟<3秒）
  - [ ] 中文分词正确（"人工智能"可被完整匹配）
  - [ ] 搜索关键字高亮显示（<em>标签包裹）
  - [ ] 搜索联想API返回相关建议（输入2字符即触发）
  - [ ] 搜索热词榜数据准确（基于实际搜索量统计）
  - [ ] ES宕机时搜索降级为MySQL LIKE（不报错）

- [ ] OSS云存储验证
  - [ ] 图片上传成功并返回可访问URL
  - [ ] 视频上传成功（支持大文件分片上传）
  - [ ] 缩略图自动生成（宽度200px）
  - [ ] CDN URL可正常访问图片/视频
  - [ ] OSS服务异常时降级到本地存储

- [ ] Push推送验证
  - [ ] 推送SDK初始化成功（注册设备Token）
  - [ ] 全部用户推送送达率 > 95%
  - [ ] 定向推送到达指定标签用户
  - [ ] 新消息触发自动Push（点赞/评论/关注通知）
  - [ ] 重要新闻发布时触发Push推送
  - [ ] 后台推送记录可查询（状态/到达率/点击率）

- [ ] 短视频播放器验证
  - [ ] MP4视频正常播放（播放/暂停/进度拖动/全屏）
  - [ ] HLS/m3u8流媒体格式正常播放
  - [ ] 清晰度切换功能正常（720p/480p/360p）
  - [ ] 播放速度调节正常（0.5x ~ 2x）
  - [ ] 自动连续播放（视频播完自动播放下一个）
  - [ ] 横竖屏自适应（手机旋转时自动切换）
