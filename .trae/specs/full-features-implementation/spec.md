
# 新闻App完整功能实现 - 产品需求文档

## Overview
- **Summary**: 实现新闻App中10项未完成的功能，包括热推页面、消息功能、现金奖励、积分商城、成就勋章、群聊功能、活动中心、创作中心、我的报料和浏览历史。
- **Purpose**: 完善新闻App的核心功能，提升用户体验和互动性。
- **Target Users**: 新闻App的所有用户群体。

## Goals
- 实现热推内容展示功能
- 实现用户消息通知系统
- 实现现金奖励相关功能
- 实现积分兑换商品功能
- 实现成就系统和勋章展示
- 实现群聊社交功能
- 实现活动展示和参与
- 实现用户内容创作功能
- 实现用户报料/投稿功能
- 实现用户浏览历史记录和查看

## Non-Goals (Out of Scope)
- 不实现视频通话功能
- 不实现在线支付功能（仅模拟积分兑换）
- 不实现复杂的审核系统（仅实现基础提交功能）
- 不实现直播功能

## Background & Context
- 项目使用Android原生开发（Kotlin）+ RuoYi后端框架（Java）
- 现已有基础的登录、签到积分、用户头像等功能
- 个人中心页面已有菜单项，但功能均为占位符
- 需要同时实现Android端界面和后端API接口

## Functional Requirements

### FR-1: 热推页面 - 显示热门推荐内容
- 用户可以查看热门推荐新闻内容
- 支持按热门程度排序
- 展示新闻的浏览量、点赞数等热推指标

### FR-2: 消息功能 - 用户消息通知系统
- 用户可以接收系统消息
- 用户可以查看消息列表
- 支持标记消息已读/未读
- 支持删除消息

### FR-3: 现金奖励 - 现金奖励相关功能
- 用户可以查看现金奖励记录
- 展示任务获取现金的入口
- 显示用户现金余额

### FR-4: 积分商城 - 积分兑换商品功能
- 展示可兑换商品列表
- 用户可以使用积分兑换商品
- 展示兑换记录
- 展示用户积分余额

### FR-5: 成就勋章 - 成就系统和勋章展示
- 用户可以查看已获得的勋章
- 展示所有可获取的勋章
- 展示成就进度
- 新成就获得时通知用户

### FR-6: 群聊功能 - 社交聊天功能
- 展示群聊列表
- 用户可以进入群聊发送消息
- 显示聊天历史记录
- 支持发送文本消息

### FR-7: 活动中心 - 活动展示和参与
- 展示活动列表
- 用户可以查看活动详情
- 用户可以报名参与活动
- 显示已报名的活动

### FR-8: 创作中心 - 用户内容创作功能
- 用户可以创建新内容（文章/帖子）
- 用户可以查看自己的创作历史
- 支持编辑和删除自己的创作
- 展示创作状态

### FR-9: 我的报料 - 用户报料/投稿功能
- 用户可以提交报料内容
- 用户可以查看报料记录
- 显示报料处理状态
- 支持上传图片

### FR-10: 浏览历史 - 查看用户浏览历史
- 记录用户浏览过的新闻
- 用户可以查看浏览历史列表
- 支持删除浏览记录
- 支持清空所有历史

## Non-Functional Requirements
- **NFR-1**: 各功能页面加载时间 &lt; 2秒
- **NFR-2**: 界面保持与现有设计风格一致
- **NFR-3**: 数据本地缓存，减少网络请求
- **NFR-4**: 所有功能支持离线查看已加载内容

## Constraints
- **Technical**: Android最低版本API 24，使用Kotlin开发；后端使用RuoYi框架
- **Business**: 必须使用现有的用户认证体系
- **Dependencies**: 依赖PrefManager进行本地数据存储

## Assumptions
- 用户已登录才能使用个人相关功能
- 后端API将配合实现
- 初始版本使用本地模拟数据，后续接入真实后端

## Acceptance Criteria

### AC-1: 热推页面可正常访问和使用
- **Given**: 用户已打开App
- **When**: 用户点击进入热推页面
- **Then**: 显示热门推荐内容列表，包含标题、封面、热推指标等信息
- **Verification**: `human-judgment`

### AC-2: 消息功能正常工作
- **Given**: 用户在个人中心
- **When**: 用户点击消息功能
- **Then**: 显示消息列表，支持查看、标记已读、删除操作
- **Verification**: `human-judgment`

### AC-3: 现金奖励页面可用
- **Given**: 用户已登录
- **When**: 用户点击现金奖励
- **Then**: 显示现金余额、奖励记录、任务入口
- **Verification**: `human-judgment`

### AC-4: 积分商城可以兑换商品
- **Given**: 用户有足够积分
- **When**: 用户在积分商城选择商品兑换
- **Then**: 积分扣除，显示兑换成功，记录保存到历史
- **Verification**: `programmatic`

### AC-5: 成就勋章展示正常
- **Given**: 用户进入成就页面
- **When**: 查看成就列表
- **Then**: 区分显示已获得和未获得的勋章，显示成就进度
- **Verification**: `human-judgment`

### AC-6: 群聊功能可用
- **Given**: 用户点击群聊
- **When**: 选择群聊并发送消息
- **Then**: 消息发送成功，显示在聊天记录中
- **Verification**: `human-judgment`

### AC-7: 活动中心功能完整
- **Given**: 用户进入活动中心
- **When**: 查看活动并报名
- **Then**: 活动详情展示正常，报名成功状态更新
- **Verification**: `human-judgment`

### AC-8: 创作中心可以创建内容
- **Given**: 用户进入创作中心
- **When**: 创建并提交新内容
- **Then**: 内容保存成功，显示在创作历史中
- **Verification**: `human-judgment`

### AC-9: 我的报料功能可用
- **Given**: 用户进入我的报料
- **When**: 提交报料内容
- **Then**: 报料保存成功，显示处理状态
- **Verification**: `human-judgment`

### AC-10: 浏览历史正常记录和显示
- **Given**: 用户浏览新闻
- **When**: 查看浏览历史
- **Then**: 显示已浏览的新闻列表，支持删除操作
- **Verification**: `programmatic`
